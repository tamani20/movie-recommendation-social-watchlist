# Movie Recommendation & Social Watchlist App

## CIS-376-002 Software Engineering II

### Project Description

The Movie Recommendation & Social Watchlist App is a responsive web-based application designed to help users discover movies, manage personalized watchlists, rate and review movies, receive personalized recommendations, and interact with friends.

## Technology Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Services
- Firebase Authentication
- Firebase Cloud Firestore
- TMDB API

### Development Tools
- GitHub
- IntelliJ IDEA
- Visual Studio Code
- Postman

## Project Architecture

React Frontend
↓
Node.js / Express Backend
↓
Firebase / TMDB API
